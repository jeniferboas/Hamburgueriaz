🍔 HamburgueriaZ - Aplicativo Android
Aplicativo mobile nativo desenvolvido em Java para gerenciamento de pedidos de hamburgueria. O projeto inclui seleção de adicionais, controle de quantidades, cálculo financeiro em tempo real e integração com o cliente de e-mail padrão via Intents do Android.
________________________________________
🛠️ Tecnologias e Ferramentas Utilizadas
•	Linguagem: Java (JDK 20)
•	IDE: Android Studio
•	Interface: XML com layout responsivo (ScrollView, LinearLayout) e estilos reutilizáveis (themes.xml)
•	Recursos do SO: Android Intents (ACTION_SENDTO) e resolução de queries no AndroidManifest.xml
•	Compatibilidade: Android 6.0 (API 23) ou superior
________________________________________
📌 Funcionalidades
•	📝 Entrada do nome do cliente
•	🧀 Seleção dinâmica de adicionais (Bacon, Queijo e Onion Rings) via CheckBox
•	➕ / ➖ Seletor de quantidade com validação para impedir números negativos
•	💰 Cálculo automático do valor total do pedido
•	📧 Disparo de e-mail estruturado via Intent (Gmail/Outlook) com o resumo completo da compra
